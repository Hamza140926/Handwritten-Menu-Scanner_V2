# Handwritten Menu Scanner

Feature for Scan2See: scan a handwritten paper menu and turn it into an
editable digital menu inside the app.

See `docs/handwritten-menu-scanner-spec.md` for the full project spec
(architecture, constraints, accuracy targets, rollout plan).

## Project structure

- `src/` — pipeline code (preprocessing, detection, recognition, postprocess)
- `notebooks/` — Colab / experimentation notebooks
- `data/samples/` — test menu photos (gitignored if large)
- `docs/` — project documentation

## Status

Planning stage. Pipeline not yet implemented.
